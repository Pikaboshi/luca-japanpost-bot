# Luca — 日本郵便 追跡通知Bot

Discord で日本郵便の荷物の追跡番号を登録すると、5分ごとに状況を確認して、変化があったときだけ通知してくれる Bot です。

## できること

- `/track` で追跡番号を登録（1人10件・全体30件まで、複数人で使えます）
- 状況が変わったときだけ通知（配達完了・不在・持ち戻りでは登録者にメンション）
- `/list` 登録中の一覧、`/stop` 追跡の停止、`/history` 配達済みの履歴
- `/scan` 伝票の写真から追跡番号を OCR で読み取って登録
  - 読み取った候補は日本郵便の履歴を確認してから自動登録
  - 履歴がない候補はボタンで登録するか、保留して最大48時間、履歴が出るまで自動で再確認
- 通知先はチャンネル／DM を切り替え可能（パネルのボタン）
- 48時間動きがない荷物には「停滞アラート」を1回だけ通知
- 共有チャンネルへの通知では、追跡番号を末尾4桁だけに伏せ、メモや担当局を表示しません（個人情報対策）

## 必要なもの

- Python 3.11 以上
- Discord の Bot アカウント（[Discord Developer Portal](https://discord.com/developers/applications) でアプリを作成し、Bot トークンを取得）
- `/scan` を使う場合のみ: Tesseract OCR 本体（日本語データは不要、数字読み取り用）
  - Windows: https://github.com/UB-Mannheim/tesseract/wiki からインストール

## セットアップ

```bash
pip install -r requirements.txt
```

トークンは次のいずれかで渡します（コードには書きません）:

1. 環境変数 `DISCORD_TOKEN`
2. ホームディレクトリの `~/.luca_token.txt` にトークンだけを書いたファイル
3. 初回起動時に対話入力（その場でファイルに保存されます）

起動:

```bash
python Luca.py
```

Bot をサーバーに入れるときの権限は、チャンネルの表示・メッセージ送信・埋め込みリンクで足ります（Permissions Integer: 19456）。

任意の設定:

- `LUCA_GUILD_ALLOWLIST`（カンマ区切りのサーバーID）: 指定したサーバー以外に Bot が参加した場合は自動で退出します
- `LUCA_CHECK_MINUTES`: 状況確認の間隔（分、既定 5）

## 注意

- `tracking_state.json`（追跡中の番号やメモが入っています）とトークンのファイルは、他人と共有しないでください（`.gitignore` 済み）
- 追跡状況は日本郵便の公開ページから取得しています。先方の仕様変更で取得できなくなる場合があります
- 他人の荷物を登録するときは、必ずその本人の了承を得てください。共有チャンネルでは番号が伏せられるとはいえ、荷物の存在自体は伝わります
